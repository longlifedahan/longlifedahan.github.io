《射箭大师》规格说明
========================

一、概述
- 平台：B站 Toy，手机横屏为主，兼容电脑
- 类型：横屏射击游戏
- 核心：调整角度 + 蓄力力度，射出直箭或抛物线箭，翻越障碍命中标靶
- 技术：原生 canvas + WebAudio，无第三方依赖；B站 SDK 异步懒加载，不阻塞页面

二、操作（底部控制栏分三行）
- 角度行：拖动滑动条调整（-90° ~ +90°），也可在数值输入框直接输入角度；电脑可用 W/S 或 上/下方向键；点击画面中的标靶可把角度自动对准该标靶（被障碍挡住的同样对准，需用合适力度翻越）
- 力度行：力度条 + 数字，蓄力时随力度上涨/回落
  - 力度条可点击/拖动设置「目标刻度」（黄色拖柄，显示力度数值）；上一箭的刻度（白色参考线）也标注力度数值，作为蓄力瞄准参考
- 按钮行：按住「蓄力」按钮充能，力度从 0 升到 100，到 100 停顿片刻后衰减，归 0 时本次蓄力自动结束（不发射，需重新按键）
  - 在目标力度处松开即发射；松开时力度为 0（或瞬间）→ 不发射
  - 蓄力过程中拖动手指到右侧「放弃」按钮松开 → 不发射；点击「放弃」同样取消
  - 电脑：按住空格蓄力，松开发射；空格蓄力到 0 自动停止（长按不重开），需松开再按；蓄力中按 Esc 或点击「放弃」取消
  - 充能速度可在「设置」中调节（蓄力速度 25~70/秒，默认 40/秒，慢速便于瞄准）
- 玩家面前有虚影指示线显示当前角度（弓的朝向与之一致）；蓄力时显示抛物线预览轨迹
- 箭与预览线离开画面后不留残影（每帧清空整画布）

三、物理
- 力度 100 → 直线箭（无重力）
- 力度 90 及以下 → 抛物线（满重力 G=150）
- 力度 90~100 → 重力按 (100-力度)/10 的 1.5 次方平滑衰减至 0，抛物线渐进为直箭，过渡不突兀
- 抛物线可越过画面上层暂不消失，随后落回
- 箭撞障碍物即消失；命中标靶加分并点亮；飞出画面即消失
- 轨迹采用分段移动 + 线段与矩形相交检测，避免高速穿透

四、关卡
- 从第 1 关开始，每关随机生成 5 个标靶与若干障碍物
- 标靶大小分三类（每关至少一个大靶、一个小靶）：大靶半径 +10~20%，小靶 -10~20%
- 价值规则（基础分）：玩家与标靶连线无障碍物 → 5~7；障碍物越多 → 越高（封顶 20）
- 体积与分数反向：大靶基础分 ×0.8~0.9（低分）、小靶 ×1.1~1.2（高分），取整，范围 4~20
- 所有标靶至少保证一种角度+力度组合可达（弧线可达，生成时逐靶验证，未达则重新布置）
- 直线不可达标靶（直线被障碍遮挡、需抛物线翻越，仍可通过弧线命中）：1-10 关至少 1 个、11-100 关至少 2 个、101-1000 关至少 3 个、1001 关起至少 4 个；可超过
- 标靶之间保持间距（不小于两半径之和 + 40），避免挤在一起
- 障碍物数量随关卡增长（平方根曲线 floor(2+√关数×1.8)，封顶 24），越后面关卡越多
- 每关 7 支箭；HUD 显示 剩余箭数/7、关卡号、累计星数
- HUD 分数显示为「当前命中价值/冲击星级所需分数 ★…」，优先显示 1 星所需（60% 总量），达成后切换为 2 星所需（80% 总量），再后为总价值（3 星需全中）
- 射中标靶立即刷新计分（不等下一箭）

五、星级判定（每关）
- 命中全部 5 个标靶 → 3 星
- 命中标靶价值 >= 总价值 × 0.8 → 2 星
- 命中标靶价值 >= 总价值 × 0.6 → 1 星
- 否则失败：累计星数 -1（最低为 0，不为负），关卡不变，下次重打同关

六、进度与存档
- 过关：累计星数 + 星级，关卡 +1
- 存档（localStorage）：关卡、累计星数、关卡内剩余箭数/分数/已命中/标靶布局/障碍布局/求助是否已用
- 中途退出（返回首页或关闭页面）自动保存，下次「继续游戏」回到原关卡原布局
- 首页提供「设置」（开关声音），无重新开始按钮

七、求助机会
- 每关 1 次，只针对单个标靶生效。点求助后选择具体标靶
- 若该标靶在当前角度可达，给出所需力度区间并扣除求助次数
- 若不可达，提示「不可达」且不扣除求助次数，可换靶或调整角度后重试

八、排行榜（仅 B站 榜）
- 等级榜（board=1）：成绩为当前关卡数
- 星数榜（board=2）：成绩为累计星数
- 周期：总榜 / 月榜 / 周榜 / 日榜
- 显示前 100 名，含名次、头像、昵称、成绩；自己的名次高亮
- 过关时自动上报；SDK 未就绪时静默降级

九、音效
- WebAudio 合成：点击、发射、命中、撞障碍、蓄力、胜利、失败；支持静音开关（记忆）
