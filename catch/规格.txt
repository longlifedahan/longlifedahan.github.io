《捕鱼达人》规格说明
========================

一、概述
- 平台：B站 Toy，手机横屏为主，兼容电脑
- 类型：横屏捕鱼游戏
- 核心：炮发射渔网，覆盖鱼判定捕获；赚金币升级渔场，解锁更高级的鱼
- 技术：原生 canvas + WebAudio，无第三方依赖；B站 SDK 异步懒加载，不阻塞页面

二、炮
- 炮位于画面底部中央贴底（炮等级控件上方），炮管短、整体小巧，炮口跟随点击/瞄准方向
- 点击画面任意处：立即朝点击方向发射渔网（核心操作）
- 按住炮口拖动：虚影指示线瞄准，松开发射
- 炮等级 lv：开炮价格 10*2^(lv-1)，捕获等级 10*2^(lv-1)，捕获范围 10+lv
- 炮等级 1~3 依次：价格 10/20/40，捕获等级 10/20/40，范围 11/12/13
- 炮等级通过炮下方「− / +」调整；上限 = 渔场等级 + 2（防止出现玩家打不动的高级鱼），达到上限提示
- 开炮按当前等级扣钱；金币不足提示"去打工赚钱"

三、渔网与捕获
- 渔网沿瞄准方向飞行，碰到鱼或抵达最远点即爆炸，形成渔网特效（0.5s 后消失）
- 爆炸半径 = min(k*(同级鱼捕获等级/100)^0.33, 150)*unit，k = max(50, 62-(炮等级-1)*1.5)（低级炮渔网更大、初期好回本，随等级收敛到 50）
- 判定：渔网中心 50% 区域命中概率 = X/Y；边缘 50% = 0.5X/Y（X 炮捕获等级，Y 鱼捕获等级，>1 取 1）
- 一炮覆盖范围内每条鱼独立判定，可同时捕获多条（鱼群聚团使一炮多鱼成为核心乐趣）
- 捕获成功：鱼消失、入账金币、金币飘字特效 + 金币音

四、鱼
- 鱼等级 lv：捕获等级 = 100*2^(lv-1)*(1+0.1*(lv-1))，价值 = 捕获等级 30%（取整）
- 鱼身上显示「等级」而非捕获等级；设置中可关闭显示
- 体型随等级线性增长（15 + 1.6*级，封顶 46*unit），lv20 才到最大体型，梯度放缓；等级越高游速越慢
- 场上鱼上限 100 条；从边缘成群游入（每群 2~6 条，组内保持聚团）、随机转向、游出画面消失
- 数量时多时少：目标数量在 22 ~ 40 间随机游走；随机 10% 概率涌入大鱼群（20~30 条聚团，一炮多鱼的高回报目标）
- 出现鱼的最大等级 = 渔场等级 + 2；等级分布 = 75% 普通鱼（1~渔场上限-4）+ 25% 精英鱼（渔场上限-3~上限）
- 鱼王：每累计生成 300~1000 条鱼触发（概率递增，1000 条必出）；通体金色带闪烁光晕特效，等级 = 当前渔场等级，价值 = 同级鱼 10~25 倍随机，捕获难度不变（按捕获等级判定），固定从左向右直线游动，出现前有金币粒子 + 大字「鱼王出现！」提示

五、金币与渔场等级
- 初始赠送金币 2000（提高开局容错）；赠送金币不参与升级与排行
- 捕获鱼获得「收入金币」（计入渔场等级升级与赚取金币榜）
- 渔场等级：初始 1 级，升到 2 级需累计收入 1000，之后每级额外
  1000*2^(k-1)*(1+0.1*(k-1))；即累计 1000/3200/8000/... 升级
- HUD 顶部显示总金币（赠送+收入合并）、渔场等级具体数字（渔场 Lv.X）与升级进度条（含百分比）；打工界面也显示渔场等级数字
- 捕获金币飘字加大加粗（描边金字），鱼王捕获时更大，增强获得感
- 升级弹出渔场升级提醒（非 alert），升级后解锁更高级的鱼与炮
- 大数格式化：超 1 亿显示「亿」，超 1 万亿亿（1e16）显示科学计数

六、打工
- 可打工条件：当前总金币 < 上限（1000*1.5^(渔场等级-1)）；总金币达到上限时点击提示「你的金币充足，继续捕鱼吧！」
- 游戏内点「打工」打开打工界面，保持界面开启才按秒累计金币
- 速率 = 20*(1+(渔场等级-1)*0.1) / 秒；关注 UP 主后 ×10
- 领取后总金币不得超过上限（可领额度 = 上限 - 当前总金币）；无"已领取累计"限制
- 界面提供「关注UP主」跳转主页与「我已关注，检测」复查关注状态
- 打工金币计入赠送金币，不提升渔场等级、不计入排行榜

七、经济平衡（经 balance.js 仿真校准）
- 数学事实：单条被覆盖鱼的期望回本贡献恒 = 0.1875×覆盖鱼数（同级炮，因成本=捕获等级）
- 回本率 = 0.1875 × 一炮覆盖的有效鱼数；普通玩家（瞄准打偏/打空）覆盖约 3.7 条 → 长期回本约 70%
- 高手（精准打鱼群 / 专挑肥群）覆盖约 6.4 条 → 长期回本约 120%
- 仿真实测（T=16 鱼群模型，25% 精英鱼）：普通回本 51%~103%（均值约 78%），高手 128%~176%（低/高等级约 130%，中等级更高=升级爽感）
- 高等级难回本根因：炮成本 ×2/级，但覆盖面积 ∝ 2^(0.67n)（∝Y^0.67），增长追不上成本；且低级鱼价值不随炮等级涨 → 每级回本约 ×0.8 衰减
- 修复：提高高级鱼出现比例（25% 精英鱼，接近渔场上限）+ 爆炸半径随同级鱼体型缩放，保证高级炮有同级目标、各等级高手都能回本
- 调参入口：game.js explosionR() 系数 50 与封顶 150（越大越富、越小越穷）；weightedLevel() 精英比例 0.25；balance.js 可重新仿真

八、测试福利

- 领取计入捕鱼收入（升级渔场 / 计入赚取金币榜），可无限领取，便于调测

九、排行榜（仅 B站 榜）
- 榜位 1 = 赚取金币榜，榜位 2 = 渔场等级榜
- 周期：总榜 / 月榜 / 周榜 / 日榜，显示前 100 名，自己名次高亮
- 赚取金币可能超过 1600 万，拆分为科学计数编码（指数×10000+尾数）存储
- 捕获后防抖上报金币榜；渔场升级上报等级榜；SDK 未就绪静默降级
